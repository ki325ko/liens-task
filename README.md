# LIENS TASK

2人で使う、シンプルなタスク管理。HTML 1枚、依存ライブラリなし。

**続けられること**を最優先に設計している。機能を足すのではなく、判断を減らす方向で作った。

## 考え方

- **判断ゼロで放り込める** — 何も付けずに Enter で登録できる。分類は後でいい
- **人が入れるのは「締切」と「★」だけ** — 緊急度は締切から自動計算する
- **今日は3つだけ** — 全部消える日を作る
- **連続日数を数えない** — 連続記録は1日切れた瞬間に離脱を生む。代わりに「今週 3日」とだけ出す
- **繰り越しに罰を与えない** — やらなかったタスクは静かに一覧へ戻る。遅延バッジは出さない

## 画面

| タブ | 中身 |
|---|---|
| **今日** | 今日やる3つ。「今日をつくる」でスコア順に自動で積む |
| **案件** | 案件ごとのカード。次の一手・進捗・止まっている案件が見える |
| **ぜんぶ** | 締切順、または案件順。担当・★・案件でしぼれる |
| **週報** | 案件を行、日を列にしたシート。週の計画と、毎日やったことの記録 |

### 週報

案件が行、日が列だけの表。**別ページ扱い**で、幅いっぱいを使う（タスクの入力欄は出ない）。

- **完了したタスクは、その日その案件のセルに自動で入る**（✓）
- セルを押すと、タスクにしていなかったことも手で足せる（・）
- 案件名の下に**目標**を書ける
- 月表示は 案件×週 の件数と、「この月にやったこと」の一覧
- 週のはじまりは既定で**水曜**。設定でどの曜日にも変えられる（記録は日付で持っているので、変えても消えない）

行に出るのは「**その週に存在していた案件**」。週の途中で足した案件はその週から出て、
完了にした案件はその週までは残り翌週から消える。過去の週を開けば当時の顔ぶれのまま見える。

終わった案件は**削除ではなく「完了」**にする。削除すると過去の週報からも消える。

右側（狭い画面では一覧の上）に**メモ**がある。タスクじゃないものを置いておく場所。
打つたびに自動で保存される。ヘッダーの「メモ」で開閉できる。
**メモは端末ごとに保存され、同期しない**（自由文は1件まるごと上書きになるので、
同期すると片方の書きかけを黙って消してしまう）。

## 書き方

```
見積りを送る #A社 @相方 !金 30分 *
```

| 記号 | 意味 |
|---|---|
| `#` | 案件（なければ自動でできる） |
| `@` | 担当（省略時は自分） |
| `!` | 締切 — `!今日` `!明日` `!金` `!8/30` `!来週` `!週末` `!月末` `!+3` |
| `〇分` `〇h` | 見積り |
| `*` | ★（重要） |

全角の `＃＠！＊★` もそのまま通る。解釈できなかった語は本文に残るので、書き損じてタスクが消えることはない。

### ★（重要）は何をしているか

人が入れる判断はこれ1つだけ。基準は設定に書いた1行で決める（既定は「今月の目標に、直接効くか？」）。

- 並び順のスコアが **+50**（「明日締切」の +35 より強い）
- **「今日をつくる」で、枠が2つ以上あるとき1枠は必ず「★あり・締切が遠い」から取る**

締切のあるものに押し流されて、重要だが急がない仕事が永久に後回しになるのを防ぐための仕組み。
基準を1つに固定するのが肝で、「大事そう」で付け始めると全部★になって効かなくなる。

一覧の各行の **「＋今日」** を押せば、開かずにそのまま今日へ入る。

## 保存と同期

- ふだんはブラウザのローカル保存だけで動く。**同期はオフでも完全に使える**
- 2人で使う場合は、設定から GitHub のトークンを入れると private リポジトリの JSON 経由で同期する
- 1件ずつ突き合わせて、あとに触った方を採用する。別々のものを触った場合は両方残る
- 削除は30日の墓標として残す（「消したのに復活」「編集したのに消える」を防ぐ）
- **トークンと設定は端末にしか保存されない。**同期もしないし、このリポジトリにも入らない
- 設定からいつでも JSON で書き出せる。読み込みは合流であって上書きではない

<https://ki325ko.github.io/liens-task/>

スマホはブラウザの共有メニューから「ホーム画面に追加」。

## 開発

ビルドなし。`index.html` を直接編集する。push すると GitHub Pages に反映される。

```
node test.mjs
```

`index.html` から `<script>` を抜き出して実行するロジックテスト。
入力の解析・スコア・今日の生成・案件・マージ・腐敗判定・メモを見ている。
画面の見た目はテストしない。
